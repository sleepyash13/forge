# Full-Stack Authentication System

A realistic full-stack application built with React, TypeScript, and ASP.NET Core. The project is intentionally designed to go beyond a simple CRUD application by introducing production-oriented concepts incrementally and only when the system has a reason to need them.

The project purpose focuses on authentication, authorization, anti-forgery protection, protected frontend routes, and containerization. Future iterations will expand the application into a modular monolith with stronger domain boundaries, background processing, messaging, observability, automated testing, and deployment infrastructure.
